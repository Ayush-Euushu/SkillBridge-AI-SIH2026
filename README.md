# SPARS - Smart Placement & Academia-Research System (SIH 2026)
### Problem Statement ID: SIH26044 | Theme: Smart Automation | Category: Software

**Team Name:** SPARS  
**Sponsoring Body:** Ministry of Ayush & AICTE (All India Institute of Ayurveda Linked)

---

## 🌟 Overview
**SPARS** is an automated national portal designed to bridge the academia-industry gap through intelligent skill mapping, live performance tracking, and direct placement pipelines. It features a robust Python/FastAPI backend coupled with an interactive Swiss luxury GovTech frontend.

---

## 🚀 Key Features & Capabilities

### 1. 📱 Virtual Smartphone SMS Simulation
* Features an interactive titanium smartphone simulator rendered directly beside the auth portal.
* Triggers realistic haptic vibrations, Web Audio API chimes, and instant SMS OTP notifications (`SPARS-GOV`) with a **"Copy & Fill"** utility.

### 2. 🗄️ Relational DBMS & Live Studio
* Powered by a persistent SQLite database mapped via SQLAlchemy.
* Includes an **Interactive Live DBMS Studio** modal allowing users to execute raw SQL queries (`SELECT`, `INSERT`, etc.) and view live results and execution times in milliseconds.

### 3. 🧠 AI Skill Gap & Target Role Engine
* Automated pipeline that assesses student profiles, extracts technical skill passports, diagnoses missing competencies against 2026 industry blueprints, and generates personalized learning pathways.

### 4. 🎓 🏢 🏛️ Triple Stakeholder Portals
* **Student Portal**: Live readiness index, CGPA tracking, skill gap radial gauges, and digital offer letter previews.
* **Industry Portal**: Direct corporate posting of internship listings and AI pre-screened candidate matching.
* **Academia Portal**: Automated syllabus-to-industry gap matrix and institutional MoU management.

---

## 🛠️ Tech Stack
* **Backend:** Python, FastAPI, SQLite, SQLAlchemy, Pydantic, Uvicorn
* **Frontend:** Vite, Vanilla JavaScript (ES6+), HTML5, Custom CSS Design System (Light/Dark themes)
